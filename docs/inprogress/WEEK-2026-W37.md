## 4. WHAT GOT DONE THIS WEEK (short)

**★ SuperTuxKart in-game is NOT blocked — corrected.** `stk --race-now --track=hacienda
--numkarts=3` reaches a real race over netboot, **0 faults** — Hacienda dirt track, race timer,
minimap, opponents, full lighting and HUD. Screenshot-quality.

**⚠️ Its frame rate: ~1.0 fps, now MEASURED rather than inferred.** I gave you three wrong
numbers today (0.35, then 1.0, then 5.6) from three bad instruments. Settled by instrumenting
the driver: **32 frames per 32.00 s wall over six consecutive windows = ~1000 ms/frame**. The
first ~1 fps figure was right. Why 5.6 was wrong: STK's `Average FPS` counts **physics ticks**,
not frames (`main_loop.cpp:644` calls `updateWorld` once per tick, ~6 ticks/frame) — so use the
flip counter, not STK's number.

**Measured frame budget** (`rpi4-v3d 547a70c`, bounded diagnostic; hacienda, 1 kart, 1080p):

| component | per frame | share |
|---|---|---|
| 8 CL submits | ~150 ms | 15% |
| ~120 other V3D ioctls | ~0.35 ms | ~0% |
| `fb_flip` mailbox | ~0.15 ms | ~0% |
| CPU sim (`--no-graphics`) | ~23 ms | 2% |
| **unaccounted CPU** | **~825 ms** | **83%** |

**Ruled out by measurement:** render passes (disabling the entire deferred pipeline — verified,
zero of those shaders compile — bought **1.7%**); GPU submit cost (15%); the VideoCore mailbox
page-flip (1–9 ms per *32* frames — this was my leading hypothesis and it is refuted, though the
code is ugly: it mmaps + munmaps two pages per frame on an unarbitrated FIFO); audio; kart count.

**Leading hypothesis, NOT yet proven:** the winsys maps **every** BO `MAP_UNCACHED` by default
(`v3d_phoenix_winsys.c:979`) — vertex, uniform, texture *and* command-list memory — so every byte
Mesa's CPU side writes is an uncached store. Fits all of it: resolution-invariant, pass-invariant,
CPU-side, invisible to ioctl timing; and explains QuakeSpasm's ~40 fps (it uploads far less). Next:
a cheap on-target uncached-vs-cached memcpy bandwidth test, then a cached-BO diagnostic build.
Detail: `docs/misc/2026-09-08-stk-frame-budget.md`.

⚠️ The diagnostic is in all five game binaries on the NFS export (24 UART lines/run, nothing on
HDMI). **The flashable image `486acda5…` predates it and is clean.** Remove when the step closes.
