## 3. IN PROGRESS

**SD card driver — "full speed + correctness"** (the standing `/loop` goal; card now in the Pi)
- Baseline measured on HW: **write 16.04 MB/s (PIO), read 30.67 MB/s**, correctness OK, SD ext2 root mounts on the current kernel.
- ⚠️ Flipping the SDMA-write gate (`bcm2711-emmc/sdcard.c:1625`) went badly: after a gate-ON boot, `/bin/sdtest` on the card read back as "not an executable". Gate **reverted**; write path verified structurally correct (the bounce copy-in for writes *is* present).
- ⚠️ I bricked one boot adding a probe-only `bcm2711-emmc` to the nfsroot script → `phfs: bcm2711-emmc - alias is already in use`. **Reverted; boot restored.**
- Two facts that must shape the next attempt: (a) **boot source varies** between TFTP and the card's own FAT across runs; (b) the card negotiates **different speed modes** across boots (`UHS-I DDR50 1.8V` vs `High-Speed 3.3V`) — so every measurement must log the negotiated mode.
