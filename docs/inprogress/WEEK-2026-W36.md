- **Quake II — root cause was ours, not upstream's.** `GL3_EndFrame` calls, pre-swap, `glInvalidateFramebuffer(GL_FRAMEBUFFER, 3, {GL_COLOR_ATTACHMENT0, GL_DEPTH_ATTACHMENT, GL_STENCIL_ATTACHMENT})` under `#ifdef YQ2_GL3_GLES`. On a windowed GLES driver that is a **no-op hint** — those enums are invalid on the winsys framebuffer. But our SDL2 glue redirects the client's "default framebuffer 0" to a **real user FBO** backed by the scanout buffer, so the enums are valid, Mesa reaches `v3d_invalidate_resource`, and the still-unflushed job **loses its colour tile store** — the page flip then presents a buffer the GPU never wrote. Fixed in the glue (a `PHOENIX_glInvalidateFramebuffer` wrapper that drops the call while a scanout FBO is bound), not in the game source, so the whole class is closed for any GLES client and the game tree stays pristine.
- **Quake III — a libphoenix bug, found by resolving the fault PC.** `far=0x10`, `esr=0x92000047` (a *write*, translation fault) at `pc=0x00d52b64` → `lib_listRemove` (`sys/list.c:46`), and 0x10 is the `next` offset in `FILE`: stdio's open-FILE list is libphoenix's only `lib_list` user, so the **same FILE was unlinked twice**. First removal NULLs both links, the second did `t->prev->next = t->next` through a NULL prev. Two layers fixed: `lib_listRemove` now treats NULL links as *not linked*, and `fclose()` **unlinks first** (`file_unlink`/`file_release` split) so a double close cannot fflush freed memory, close a reused fd, or free the block twice.
- **GPU X11 — wmaker was running all along; the black root was a missing helper.** wmaker does not paint the root itself: `src/misc.c:953` execs `wmsetbg`. The port built `util/wmsetbg` (3.0 MB) but never installed it, so the root stayed pure black even though the seeded defaults already set `WorkspaceBack = (solid, "rgb:50/50/75")`. The frame at 0.7% non-black in fact showed a healthy session — Dock, workspace `Main` button with readable text, live cursor. **Both of us misread the same screenshot the same way, which says the default was wrong, not the reader.** `wmsetbg` + `wdwrite` now ship, with a `b_die` if either is missing. HW: root paints, **100% non-black** (was 0.7%).
