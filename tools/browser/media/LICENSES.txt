Phoenix-RTOS streaming-video test set -- licences of the third-party test assets (2026-10-07)

These are TEST ASSETS for the browser's HLS/MSE work (docs/browser/MSE-DESIGN.md §9). They are
fetched by tools/browser/media/stage.sh into external/browser-media/ (git-ignored), served from the
host by serve-media.py and copied to the Pi's NFS root (/usr/share/browser-media); they are not part
of any Phoenix-RTOS repository and are not shipped in an image.

hls.js 1.7.3      npm package hls.js@1.7.3 (https://registry.npmjs.org/hls.js/-/hls.js-1.7.3.tgz),
                  sha256 in tools/browser/media/hls.js.sha256 (the tarball also matches npm's
                  sha512 integrity string). Apache License 2.0, Copyright (c) 2017 Dailymotion;
                  its LICENSE file is staged beside dist/hls.min.js (vendor/hls.js/LICENSE). Used
                  unmodified.

Test media (artifacts/media/: renditions, ladders, mse): generated by gen-ladders.sh from
FFmpeg's built-in testsrc2/sine sources with the host's ffmpeg (libx264/libx265: GPL encoders --
the encoders' licence does not extend to their output). No third-party footage.

The test set's own files (pages/*, serve-media.py, gen-ladders.sh, ladder-manifest.py, mp4box.py,
check-media.py, stage.sh, serve-for-pi.sh, run-host-pages.sh, pi/b8-stream.sh): BSD-3-Clause.
